Privacy Policy

Application: rclone-a1drive. Last updated: 2026-11-25.

Who uses this application

rclone-a1drive is a personal tool. The owner of this website is the only user. The application is not offered to the public.

What the application does

The application uses rclone to copy encrypted backup files from the owner's computer to the owner's own Google Drive. The application reads those files back to verify them.

What data the application accesses

The application accesses only the Google Drive of the account that signs in, and that account is the owner's account. The application does not access the data of other people.

What the application stores and shares

The access token stays on the owner's computer. The application does not send Google user data to other servers. The application does not sell, share, or transfer Google user data. The application does not use Google user data for advertising or to train AI models.

Google API Services User Data Policy

The use of information that the application receives from Google APIs obeys the Google API Services User Data Policy, which includes the Limited Use requirements.

How to remove access

To remove the access of the application, go to Google Account permissions and remove rclone-a1drive.
